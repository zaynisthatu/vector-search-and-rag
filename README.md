# vector-search-and-rag

Embeddings and vector-database projects.

| Folder | What it is |
|---|---|
| [`vault-semantic-search/`](vault-semantic-search) | Semantic search for the VAULT archive viewer: sentence-transformers embeddings stored in Qdrant, next to BM25 keyword search and typo-tolerant Meilisearch search. Indexing and search scripts with a test. |
| [`chroma-rag-colab/`](chroma-rag-colab) | Colab notebook: Qwen chat model with file retrieval on Chroma (MiniLM embeddings) and web search, behind FastAPI and Gradio. |
